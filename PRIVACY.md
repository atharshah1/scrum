# Privacy Policy

**Last Updated:** January 2026

## 1. Introduction
The **Scrum CLI** ("the Application") is a command-line tool designed to help users interact with Atlassian Jira directly from their terminal. We value your privacy and are committed to protecting your data.

## 2. Data Collection and Storage
The Application does **not** collect, transmit, or store any personal data on external servers owned by the Application developers.

*   **Local Storage:** Authentication tokens (OAuth Refresh Tokens) are stored securely in your operating system's native keyring/keychain. Configuration files (such as the currently selected project context) are stored in your local user home directory.
*   **Direct Communication:** All data requests (fetching issues, creating projects, etc.) are made directly from your computer to Atlassian's APIs. No data passes through any intermediate servers.

## 3. Third-Party Services
The Application integrates with **Atlassian Jira**. When you log in, you authorize the Application to access your Jira data subject to Atlassian's Privacy Policy.

## 4. Analytics
The Application does not contain any tracking scripts, analytics, or telemetry.

## 5. Contact
If you have questions about this policy, please check the repository where this tool is hosted.
